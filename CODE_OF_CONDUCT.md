# Code of Conduct

Chawpick IDE is an open-source project built together with its community. However big it grows,
we want it to stay a place where everyone enjoys taking part, from first-time contributors to
seasoned developers.

## Standards

**We expect:**

- **Respect.** Disagree with ideas, not with people.
- **Good faith.** Most misunderstandings aren't malicious. Ask before assuming the worst.
- **Patience with newcomers.** Everyone started somewhere.
- **Useful feedback.** Give it kindly, and accept it gracefully.
- **Focus.** Keep issues, pull requests and discussions about Chawpick IDE.

**We do not tolerate:**

- Harassment, insults, slurs, threats or personal attacks.
- Discrimination of any kind: age, disability, ethnicity, gender, sexual orientation, religion,
  nationality, experience level or anything else.
- Sexualized language, imagery or unwanted attention.
- Publishing someone's private information without their permission.
- Spam: ads, unrelated links, or AI-generated text that doesn't engage with the conversation.

## Scope

This applies in every project space: issues, pull requests, discussions, commits, code review,
our [Discord](https://discord.gg/Dx4YUqgrm9), and any community space we open later. It also
applies when someone represents the project in public.

## Reporting

If you see or experience a violation, email **contact@alttiplano.com** with this subject:

```
[Chawpick IDE conduct] Brief description
```

Include links, screenshots and any context that helps. Every report is read and kept
confidential: we never share who reported.

## Enforcement

Maintainers may edit or delete content, lock threads, and block accounts. We start with the
lightest step that solves the problem. Serious or repeated violations can skip steps.

| Step | When | What happens |
|---|---|---|
| 1. Correction | Rude or unwelcome behavior | A private note explaining what went wrong |
| 2. Warning | A serious incident, or the same behavior again | A formal warning: next time means a ban |
| 3. Temporary ban | Sustained or severe violations | No participation in the project for a set time |
| 4. Permanent ban | A pattern of violations, harassment or hate | Removed from all project spaces for good |

## Contributing

We value every kind of help: bug reports, code, documentation, translations and answering
questions. See [CONTRIBUTING.md](CONTRIBUTING.md) to get started.
